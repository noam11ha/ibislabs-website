# Single counsel question — pre-launch privacy review

> Ibis Labs' gut-health quiz will not initialize Meta tracking unless the user checks an optional, unchecked box. If enabled, selecting Start—before any quiz answer is submitted—sends only a generic `QuizStart` event through Meta Pixel and Conversions API, with IP address, browser user-agent, a URL stripped of query parameters, and Meta `_fbp`/`_fbc` identifiers if present. Ibis does not send Meta quiz answers, quiz completion, symptoms, diagnoses, medications, red flags, inferred profile, protocol match, name, or email. Does this Start event constitute sharing consumer health data under the laws applicable to our US launch, and if so, is the proposed separate opt-in sufficient? Please assess the legal-consent question separately from whether Meta's own Business Tools Terms permit the event.
